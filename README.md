## 2026-09-24 提交审核前整改

## 运行

使用微信开发者工具打开本目录，使用此小程序自己的 AppID。请求、上传、下载合法域名均为 https://api.lanxin.cyou。不要关闭真机的域名或 TLS 校验。服务端配置微信 AppID/AppSecret 和 ZeoAPI 凭据；这些秘密不得写入小程序包。

无需微信云开发环境。app.js 初始化共享 utils/api.js 客户端，wx.login 换取业务登录后调用 API；用户登录失败时保留页面并显示请求错误，不会把本地演示当作已提交。

## 数据模块

- 智能剪辑：比赛视频上传、Worker 实际识别片段、选择后合成、本人历史及保存。识别为空就显示真实空结果。
- 赛事资讯与报名：服务端目录、报名校验、名额与幂等提交。空数据库显示空列表。
- 个人成长：训练、个人资料、本人比赛数据使用后端；临时头像先上传，再保存资料。
- 商城：服务端商品价格和库存、本人的未支付订单；清空列表为软隐藏，不删除交易记录、不代表取消或支付成功。原页面仍保留“模拟下单”文案；当前不包含微信支付或履约功能。
- 自定义比赛：保留本地可恢复草稿，串行同步、版本校验；离线草稿不等于服务端已确认。
- AI 助手：通过本后端的 /api/comptrain/chat/completions 访问 ZeoAPI，保留 SSE/Markdown 展示，客户端没有供应商密钥。

正式赛事、商品、库存需要运营方提供，部署不导入前端示例商业数据。lanxin-bansai 分支不属于本次工作；域名可共用父域，后端账号、JWT、数据和队列按实例隔离。
