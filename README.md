# 篮球数据统计小程序

## 项目简介

篮球数据统计小程序是一个基于微信小程序开发的篮球数据管理工具，旨在帮助篮球爱好者和球队管理者方便地记录、分析和管理篮球比赛和训练数据。

## 功能特点

### 1. 首页
- 显示个人基本信息和最近比赛数据
- 提供快速访问其他功能模块的入口
- 展示关键数据统计和分析
- 现代化UI设计，带有流畅的动画效果

### 2. 赛事模块
- 比赛列表展示
- 日期选择功能（默认选择今天）
- 比赛详情查看
- 比赛状态实时更新
- 增强的搜索和筛选功能

### 3. 训练模块
- 技能雷达图展示（优化后的视觉效果）
- AI智能体聊天功能（悬浮按钮式访问，接入方舟API）
- 训练计划管理
- 训练记录功能
- 快速训练模式

### 4. 个人中心
- 个人资料管理
- 个人数据统计和可视化
- 资料编辑功能
- 现代化卡片式布局

### 5. 创建模块
- 创建新比赛
- 记录比赛数据
- 生成比赛报告
- 精彩片段标记和管理

## 技术栈

- **前端框架**：微信小程序原生开发
- **UI设计**：现代化蓝色主题，毛玻璃效果，渐变背景
- **数据存储**：微信小程序本地存储
- **API接口**：方舟API（AI智能体）
- **图表库**：Canvas 2D API（雷达图）
- **组件开发**：自定义悬浮按钮组件

## 安装与运行

### 前提条件
- 安装微信开发者工具
- 注册微信小程序账号
- 获取方舟API密钥（用于AI智能体功能）

### 安装步骤
1. 克隆本项目到本地
2. 打开微信开发者工具
3. 导入项目
4. 在`pages/chat/chat.js`和`pages/training/training.js`中配置方舟API密钥
5. 编译并运行项目

## API接口说明

### AI智能体接口
- **接口地址**：`https://ark.cn-beijing.volces.com/api/v3/chat/completions`
- **请求方式**：POST
- **请求头**：
  - `Content-Type: application/json`
  - `Authorization: Bearer {API_KEY}`
- **请求体**：
  ```json
  {
    "model": "ep-20260322162122-hgksb",
    "messages": [
      {"role": "system", "content": "你是人工智能助手"},
      {"role": "user", "content": "你的问题"}
    ]
  }
  ```

## 设计特色

1. **现代化UI**：采用蓝色主色调，配合毛玻璃效果和渐变背景，营造专业的视觉体验
2. **流畅动画**：添加了丰富的过渡动画和交互效果，提升用户体验
3. **响应式设计**：适配不同屏幕尺寸，确保在各种设备上的良好显示
4. **交互反馈**：所有可交互元素都有明确的视觉反馈，提升用户操作体验
5. **统一设计系统**：使用CSS变量管理设计令牌，确保整个应用的设计一致性

## 注意事项

1. 本项目使用现代化蓝色主题设计，视觉效果美观且专业
2. AI智能体功能需要有效的方舟API密钥
3. 部分功能可能需要网络连接才能正常使用
4. 数据存储在本地，卸载小程序后数据会丢失
5. 悬浮AI按钮可在任何页面访问，点击即可进入AI对话界面
